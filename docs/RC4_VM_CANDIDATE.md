# rc.4 ベース VM 検証版

過去のvm.1検証記録です。現在の構成・制限・公開判断は
`issues/ISSUE-208.md`と`releases/2.0.0-rc.6-rc4-vm.4.md`を参照してください。

## 土台と変更範囲

- 基準: `v2.0.0-rc.4` (`9973a8e`) / Forge 1.20.1。
- 検証版: `2.0.0-rc.6-rc4-vm.1`。公開済み rc.4/rc.5 の置き換えではありません。
- VM フォークの `aco-exact-vm 0.1.1` を Jar-in-Jar 同梱。
- 固定入力・単一出力・共有依存のない非循環グラフの数量計算を VM に委譲。
- VM 内部の要求数・在庫・必要量・実行回数・不足数は BigInteger。long 上限で丸めません。
- 複数候補・副産物・返却容器など、VM の対象外は rc.4 の計算方法を維持。
- 在庫の増減で不変スナップショットの計算まで打ち切る条件を修正。
- 実際の材料確保、同時注文の排他、取消返却、CPU 実行は既存処理を維持。
- 遅延取得する exact 在庫は、異なる時点の通常在庫と混ぜない検査を維持。

rc.5 の LinearWidePlanning・反復計算変更、rc.6 の新しい注文画面・通信形式・
搬入出変更は持ち込んでいません。開発環境の GameTest 用に、既存メニューの
Mixin 2箇所へ名前付きメソッドの別名を追加しています。本番の対象は変更していません。

## 検証

- 通常テスト: 627件中621成功、既存skip 6件、失敗0件。
- VM フォーク: 7件成功。
- 実 AE2 GameTest: 6件成功。
- 在庫変化による失敗は修正前に2試験で再現。修正後は、注文完了と在庫不足時の
  提出拒否を確認。別時点の exact 在庫の混入拒否も確認。
- 同梱ライブラリのバイト一致、ライセンス、クラス、別MOD初期化非混入を確認。

これは実サーバーの全レシピ・GUI・巨大注文完了の保証ではありません。
全工業レシピの VM 対応、BigInteger 数量を直接入力する新 UI、実環境での
計算時間測定は、この rc.4 ベースへの追加には含みません。
