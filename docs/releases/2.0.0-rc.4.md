# AE2 Crafting Optimizer 2.0.0-rc.4

## Prerelease / プレリリース

A test release of the current #190 work, not a stable or all-recipes-complete release.
Issue #190 remains open. Back up the world/config, finish or cancel active large
crafting jobs before upgrading, and match server/client ACO versions. Do not rely
on downgrade compatibility for jobs saved by this prerelease.

現在の実装をまとめた試験版です。安定版や全レシピ対応の完成宣言ではありません。
ワールド・設定をバックアップし、進行中の巨大クラフトを完了または取消してから更新してください。
サーバーとクライアントのACOを同じ版にそろえてください。この版で保存したジョブの旧版への引継ぎは保証しません。

## Improvements Since rc.3 / 改善内容

- Preserve AE2 candidate/input order when trying multiple producers, roll back unsuccessful branches and reuse only proven repeated segments.
  複数の製法や代替素材をAE2の順序に沿って検討し、失敗した枝の計算を巻き戻します。同じ処理の再利用は正しさを確認できる範囲で行います。
- Separate immutable pattern capture from server-side dynamic input/returned-item checks, and revalidate before adoption. Inspect supported scaled processing patterns without silently losing their quantities.
  パターンの構造取得と、NBT・耐久値・返却物などの実判定を分離。対応する拡張加工パターンの倍率も正確に取得します。すべての独自パターンへの対応ではありません。
- Carry selected fixed-input, acyclic crafting-table branches into exact physical execution, retaining chosen recipes, counts, dependencies and surplus through saving.
  固定入力で循環しない作業台クラフトの分岐を、選択済みの製法・回数・素材・余剰を保ったままBigInteger実行へ引き継ぎます。
- Reduce repeated physical-step scans/accounting rebuilds. Validate worker receipt identity and credited outputs, and wait safely for a lagging worker save instead of crediting twice.
  実行中の重複走査・集計を削減。受領記録と成果物を検証し、保存のタイミング差では二重計上せず復旧を待ちます。
- Fix intermediate arithmetic falsely rejecting an in-range CPU byte cost. Keep exact whole bytes/fractions and round once, leaving AQE in charge of available capacity.
  AQEの容量内なのに途中計算で誤拒否する不具合を修正。液体・ガスを含め端数を正確に扱い、空き容量の管理はAQEに任せます。10^64の固定上限は追加しません。

## Verification / 検証

Automated checks cover AE2 differential accounting, selected branches, immutable
snapshots, receipts, cancellation, NBT and CPU-capacity boundaries. The physical
lifecycle tests run production accounting/codecs with world/storage/worker doubles.
AQE profiles include the default 1,024 digits and effective limit of 16,384 digits.
The supplied Forge AQE 2.2.7 bytecode check verifies constants only, not NeoForge
AQE runtime compatibility.

AE2との会計比較、分岐、スナップショット、受領記録、取消、保存復元、容量境界を自動試験しています。
物理実行試験は実際の会計・保存処理を呼びますが、ワールド・倉庫・作業設備は模擬です。
AQE既定の1,024桁と構造上限16,384桁を検査しています。実ゲームでの完了や処理速度の保証ではありません。

## Remaining Tasks / 残っている課題

- Verify live AQE/AAC completion, exact refunds, restart recovery and concurrent reservations.
  実ワールドのAQE/AACで、巨大注文の完了・過不足のない取消返却・再起動復旧・同時予約を確認する。
- Extend wide physical execution beyond fixed-input acyclic crafting-table branches.
  加工機械、循環、動的入力、同じ工程へ交互に戻る分岐などのBigInteger実行対応を広げる。
- Identify remaining uncaptured/ineligible patterns in the real ME network and add evidence-backed compatibility.
  実ネットワークで情報取得や高速化の対象外になるパターンを特定し、実データに基づいて互換性を追加する。
- Measure and achieve sub-10-second full-tree planning for the creative control circuit at the target huge quantity.
  クリエイティブ制御回路を約922京個発注する全レシピツリーの計画を10秒未満で終える目標を検証・達成する。現時点では未達成確認ではなく、未検証です。
- Measure real server-thread cost, allocation, concurrent-order latency and item/fluid/chemical transfer overhead.
  サーバースレッド負荷、メモリ使用量、同時注文の待ち時間、搬入搬出負荷を実環境で測り、改善する。

Unsupported plans still fail safely or use an allowed pre-ownership fallback;
this is not unconditional replacement of AE2 crafting. No recipe/progression,
external CPU ownership or JVM/GC fix is included. No production deployment was
performed as part of publishing this release.

未対応の計画は安全に拒否するか、素材を取得する前に限って標準経路へ戻ります。
レシピ・進行度・外部CPUの管理権限は変更していません。JVM・GCの修正は含みません。
この公開作業では本番サーバーへの配置・再起動はしていません。
