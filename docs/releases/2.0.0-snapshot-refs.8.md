# 2.0.0 Snapshot refs.8 - NeoForge 1.21.1

**Alpha snapshot, not a stable 2.0.0 release.**

Authoritative behavior: Forge 1.20.1 `f93adc1` (refs.8).
VM source: `syarukasu/AE2-VM-ACO` at
`5b57a00e283d355a47ee5276ba528b2dcf7d07db`.

- Port the refs.8 BigInteger VM calculator and exact-accounting bridge to AE2 19.2.17.
- Retain NeoForge data-component, registry-aware codec and networking APIs.
- Match AE2 19 stock acquisition: refresh player orders; use cached network stock for requesters.
- Adapt captured pattern lists, vanilla matching rules and optional GTCEu/Mekanism lookup targets.
- Exclude legacy calculation/deduplication hooks while the bundled VM owns planning.
- Do not impose ACO throughput limits on ordinary AE2 or Neo ECO execution.
- Bundle exact/native VM libraries; no separate VM installation. Comparison-only solvers are not included.
- Preserve the existing NeoForge public API against the previous rc.5 artifact's compiled signatures.

## Requirements

Minecraft 1.21.1, NeoForge 21.1.247 or newer, Java 21, AE2 19.2.17 (19.x).
Use the bundled artifact under `build/distributions/2.0.0-snapshot-refs.8/`.
The `NOT-FOR-INSTALLATION` intermediate artifact is not a playable mod.
Do not install the Forge 1.20.1 artifact in NeoForge.

## Unverified Acceptance

Client/server startup and real-world industrial planning are not proven by compilation or unit tests.
Wide physical completion, cancellation/refunds, restart recovery, simultaneous orders and
sub-10-second creative-control-circuit planning remain pending. No production deployment or restart
was performed as part of this port.

The Forge reference branch's CI run 37429047093 failed the GameTests
`ae2.aco_vm_ae2_lifecycle` and `ae2.aco_vm_substitution_queries`.
This NeoForge port does not claim those runtime failures are fixed.

## Reproduce

Follow `.github/workflows/build.yml` for the pinned mod dependencies. Check out the pinned VM
commit into a separate directory; do not invoke the VM repository's root build.

```powershell
./gradlew.bat clean build verifyIssueRegressionReleaseReadiness "-PacoLocalModsDir=C:/path/to/compile-mods" "-PacoVmForkDir=C:/path/to/AE2-VM-ACO"
```

Java 17 is additionally required for the exact VM library's build toolchain.
Both VM source JARs accompany the distribution under `sources/`.
