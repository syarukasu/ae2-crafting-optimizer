# ACO 2.0.0 Snapshot: vm-refs.8

Experimental Alpha for Forge 1.20.1 / Java 17. This is not stable 2.0.0.
Internal version: `2.0.0-rc.7-vm-refs.8-local`.
CurseForge file: [9077511](https://www.curseforge.com/minecraft/mc-mods/ae2-crafting-optimizer/files/9077511).

## Changes and boundaries

See the [feature-by-feature call-path audit](../FEATURE_AUDIT_REFS8.md) for the
distinction between active runtime integrations and retained legacy classes.

- BigInteger VM arithmetic, order-local stock and shared captured input semantics.
- Funded alternative producers are tried before hypothetical missing inputs.
- Eligible fixed-graph Requester CRAFT_LESS searches use shared demand coefficients.
- Aggregation retains the union of visited capacity nodes across stock boundaries.
- Ordinary provider throughput remains native; no new retry or transfer limits.
- Retired graph/SMT solvers remain test fixtures, excluded from runtime jars.

Detailed local evidence: [requester quantities, capacity and timings](../issues/evidence/ISSUE-218-REQUESTER-2026-10-06.md).
The synthetic arithmetic benchmark is not a live-server speed claim.
Full wide execution, cancellation/refunds, restart recovery, concurrent orders,
original live false-shortage verification and the final sub-10-second industrial
target remain pending. The 1.21.1 port needs separate platform evidence.

Back up worlds/configuration. Install the same bundle on clients and server;
do not add separate copies of the bundled VM modules.

## Build from public source

Requirements: Git, JDK 17, network access to dependency repositories. The Gradle
wrapper and CI download all build dependencies; no production pack is required.

```sh
git clone --branch snapshot/2.0.0-refs.8-1.20.1 https://github.com/syarukasu/ae2-crafting-optimizer.git aco
git clone https://github.com/syarukasu/AE2-VM-ACO.git vm
git -C vm checkout 5b57a00e283d355a47ee5276ba528b2dcf7d07db
cd aco
./gradlew test build verifyExactVmBundle verifyIssueRegressionReleaseReadiness -PacoExactVmDir=../vm/exact-engine
```

On Windows use `gradlew.bat`. For pinned offline artifacts, follow
`.github/workflows/build.yml` and pass `-PacoLocalModsDir=/path/to/mods`.
The CI pins both upstream AE2 15.4.10 and UELM 15.5.0-uelm profiles.
GameTests are a separate CI step and not a production-world acceptance test.

Installable output:
`build/distributions/2.0.0-rc.7-vm-refs.8-local/aco2.0.0-rc.7-vm-refs.8-local_1.20.1.jar`.
Matching bundled-module sources are in the adjacent `sources/` directory.
The previously uploaded binary's SHA-256 is
`DCD10CB901E10C25BB412EC9CFDEE454925179C8005B16C42A92BFB1DD0F36E5`.
Packaging timestamps can differ on rebuild; do not equate a different ZIP hash
with different runtime class bytes without comparing the actual entries.

Only source, tests, build configuration and sanitized development documentation
are published. Local logs, worlds, profiles, backups and compiled dependencies
are not part of the repository snapshot. Historical evidence is retained as
history, not silently upgraded to current acceptance.
