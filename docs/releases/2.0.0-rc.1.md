# AE2 Crafting Optimizer 2.0.0-rc.1

## Release Candidate / リリース候補版

This is a prerelease, not the stable 2.0.0 release. Back up your world and config
before testing. Install the matching ACO version on the server and all clients.

正式版2.0.0に向けたプレリリースです。導入前にワールドとConfigをバックアップし、
サーバーと全クライアントでACOのバージョンを揃えてください。

| Artifact / ファイル | Minecraft | Loader / ローダー | Java |
| --- | --- | --- | --- |
| `aco2.0.0-rc.1_1.20.1.jar` | 1.20.1 | Forge 47.4.18+ | 17 |
| `aco2.0.0-rc.1_1.21.1.jar` | 1.21.1 | NeoForge 21.1.247+ | 21 |

The suffix is the Minecraft version, not part of the mod version.
Both files are ACO **2.0.0-rc.1**. Use only the one for your Minecraft version.

末尾はMinecraftのバージョンです。MODのバージョンはどちらも
**2.0.0-rc.1**です。自分の環境に合う片方だけを使用してください。

## Improvements / 改善内容

- Reuse generation-bound graphs, inventory snapshots and calculation-local results
  to reduce repeated planning work. Let long ingredient searches yield through
  AE2's existing tick budget and reuse its candidate indexes.
- Keep checked long arithmetic and exact BigInteger promotion, including overflow
  originating in inputs, intermediate amounts, pattern counts, outputs or bytes.
- Compile deterministic processing patterns with independent byproducts.
  Preserve every output and include fluid/gas byproduct counts in overflow and
  execution-window checks.
- Expose the existing receipt-backed physical crafting transaction through public
  API version 1 for CPU add-ons. Prevent normal AE2 ticking from also executing
  an exact-owned job.
- Remove duplicate legacy execution ownership and the extra planner executor.
  Mekanism retains its own machine recipe lookup.

- 世代付きグラフ・在庫Snapshot・一計算内の結果を再利用し、重複する探索を削減。
  長い素材照合はAE2本来のtick予算で中断・再開し、既存の候補索引を再利用します。
- 入力・中間素材・実行回数・出力・容量のどこでlongを超えても、
  正確なBigInteger計算へ引き継ぐ境界を改善しました。
- 他工程で再利用しない副産物を持つ加工パターンを高速計算へ対応。
  液体・ガスを含む全出力を保持し、副産物だけの数量超過も検査します。
- 既存の実クラフト取引をCPUアドオンから利用できる公開API v1を整備。
  exact処理と通常AE2処理が同じジョブを二重実行しないよう修正しました。
- 重複していた旧実行処理と追加の計算executorを整理。
  Mekanismの機械レシピ探索はMekanism自身に任せます。

## Compatibility / 互換性

AE2 is required; CPU and machine add-ons are optional. Forge builds target
AE2 15.4.10 and are also compiled/tested against 15.5.0-uelm. NeoForge targets
AE2 19.2.17. This is not a claim of live compatibility with every add-on version.

The Forge-only tagged crafting validation cache is scoped to one calculation
and known vanilla recipe/ingredient implementations. It preserves full AEItemKey
NBT identity. Its NeoForge port is deferred because that AE2 implementation has
a different component-cache contract.

2.0 removes the old Pattern Batch V1 API and ACO-owned external CPU execution.
Add-ons using those old internals need an updated integration. ACO alone does
not add BigInteger execution support to an incompatible CPU add-on.

AE2が必須です。CPU・機械アドオンは任意です。Forge版はAE2 15.4.10を基準とし、
15.5.0-uelmでもビルド・試験します。NeoForge版はAE2 19.2.17が基準です。
任意アドオンの全バージョンで実機動作を保証するものではありません。

NBT付き作業台素材の追加キャッシュはForge版のみです。既知のバニラRecipe・Ingredientを
対象に、一計算内で完全なAEItemKeyを区別します。NeoForge版はAE2側の契約が異なるため
この追加最適化を保留しています。

2.0では旧Pattern Batch V1 APIとACOが外部CPUの実行を所有する処理を削除しました。
旧内部実装に依存するアドオンには対応更新が必要です。
ACOだけを更新しても、未対応CPUアドオンでBigInteger実行が可能になるわけではありません。

## Known Limitations / 既知の制限

- Coupled byproduct reuse, ambiguous producer selection, shared-DAG AE2 byte
  equivalence and dynamic recipe validation are not universally optimized.
  Unproven normal plans still use AE2's standard calculation.
- Supreme-circuit planning speedup is not yet demonstrated in the real modpack.
- Local/CI tests do not establish completion, cancellation refunds or restart
  recovery in your world. The full new-candidate live matrix remains pending.
- No release claim of universal speedup, perfect stability or completed support
  for all industrial recipes.

- 副産物を別工程で再利用する計画、複数候補のレシピ選択、共有中間素材のCPU容量計算、
  動的レシピ判定まで一律に高速化できる状態ではありません。
  証明できない通常計画はAE2標準計算を使います。
- 実MODパックでの至高回路の計画時間短縮は、まだ実証していません。
- 自動試験の成功は、実ワールドでの完了・取消返却・再起動復旧の保証ではありません。
  今回の候補版の実機検証には未実施項目があります。
- 全レシピの高速化、完全な安定性、工業環境全体の完成を意味するリリースではありません。

Reusable-byproduct optimization is tracked in [issue #185](https://github.com/syarukasu/ae2-crafting-optimizer/issues/185).
It is proposed follow-up work, not a feature of this RC.

副産物を再利用する高速化は[Issue #185](https://github.com/syarukasu/ae2-crafting-optimizer/issues/185)で継続します。
今回のRCに実装済みの機能ではありません。

Report the Minecraft version, ACO version, AE2/add-on versions, reproduction

不具合報告にはMinecraft・ACO・AE2・関連MODのバージョン、再現手順、
該当ログを添えてください。未解決のIssueは継続して対応します。
