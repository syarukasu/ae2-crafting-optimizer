# AE2 Crafting Optimizer 2.0.0-rc.5

## Prerelease / プレリリース

Incremental planning and diagnostics update. This is not a stable release or a
claim that every industrial recipe is fast or every BigInteger job can finish.
計算処理と診断ログの改善をまとめた試験版です。全工業レシピの高速化や、
すべてのBigIntegerクラフトの完了を保証する完成版ではありません。

| File / ファイル | Minecraft | Loader |
| --- | --- | --- |
| `aco2.0.0-rc.5_1.20.1.jar` | 1.20.1 | Forge |
| `aco2.0.0-rc.5_1.21.1.jar` | 1.21.1 | NeoForge |

The mod version is **2.0.0-rc.5** in both files. AE2 is required; add-ons remain optional.
両方のMODバージョンは **2.0.0-rc.5**。末尾がMinecraftのバージョンです。AE2以外の連携MODは任意です。

## Improvements Since rc.4 / 改善内容

- Reuse mathematically proven repeated calculations for ordinary orders too,
  including repeated intermediates under a small final order (#207).
  少量注文でも、中間素材の同じ計算を安全にまとめて実行し、重複処理を減らします。
- Preserve observations from failed nested recipe branches before reusing work.
  This prevents choosing the wrong recipe after catalyst/stock availability changes (#207).
  失敗した製法の判定条件も保持し、触媒や在庫の変化を無視した製法選択・誤計算を防ぎます。
- Aggregate demand in eligible shared dependency graphs for requests beyond long,
  keeping exact quantities and logical CPU-byte charges (#202).
  条件を満たす巨大注文では、共通する中間素材の要求をまとめて計算します。
  必要数・不足数・CPU容量の計算は正確さを維持します。すべてのレシピへの適用ではありません。
- Add bounded INFO planning statistics to the normal server console/latest.log.
  During activity, report at most two lines per minute: active/completed/aborted
  calculations, routes, measured duration, cache counters and decline reasons (#209).
  通常のサーバーログに、計算中・完了・中断件数、処理経路、計算時間、
  キャッシュ利用状況と高速経路を使えなかった理由を定期表示します。
- Observe planning completion before outer return handlers can hide the existing
  observer; keep receipt/sidecar and shadow-validation ownership unchanged (#209).
  計算が完了していても完了ログが記録されない場合への対策を追加しました。
  計画完了の件数は、実際のアイテム製造完了の件数ではありません。
- Fix two Forge menu Mixin selectors in the development runtime and add real
  isolated AE2 processing/cancel/concurrent-order/container GameTests (#190).
  Forge開発環境で適用されなかったメニュー用Mixinの指定を修正し、
  加工・取消・同時注文・返却容器の隔離環境試験を追加しました。

## Diagnostics / 診断

`diagnostics.logPlanningStatistics=true` is the default. Output starts only when
planning/cache activity occurs or a tracked calculation is active. Detailed
per-order diagnostics remain in debug.log with the existing decision-flow option.
既定で統計ログは有効です。計算やキャッシュ利用などの活動がない間は出力しません。
詳細な注文単位のログは既存の設定に従ってdebug.logへ記録します。
保存済みログの読み取り専用集計ツールもソースに追加しました。元ログは改変しません。

## AE2-VM Status / AE2-VMの扱い

A pinned real-engine source probe and arithmetic patch are included in the source
tree only. The patch fixes reproduced stack overflow/narrowing cases. The exact
stock/rollback/result API is not complete. **AE2-VM is NOT bundled or activated
in these JARs**; installing this version does not switch ACO to the VM engine.
AE2-VM実装を使った検証コードと演算修正はソース側の試験専用です。
**配布JARにAE2-VMは同梱・有効化していません。** 在庫・巻き戻し・結果まで含めた
完全なBigInteger連携は未完了です。VM導入済みのリリースとは扱わないでください。
