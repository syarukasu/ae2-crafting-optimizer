# Dev.19 Dead-Code Cleanup

Local Forge 1.20.1 cleanup for #161/#218. No deployment, release, Minecraft
startup, GameTest or production benchmark was performed in this change.

## Removed

- `engine/SymbolicCraftingPlanner`: planning methods had no main callers;
  its only remaining call cleared a nonexistent topology cache. Removed that
  call from Ae2CompiledCraftingGraphCache, not the live graph/qualification caches.
- `integration/NeoEcoVersionCompatibility` and its nested enum: the native
  Neo ECO limiter Mixins and their selector had already been removed in dev.17.
  Removed the obsolete parser-only test; retained packaging/bootstrap contracts.
- Four private PatternCompiler global collections, initialized but never used:
  COMPILED_PATTERNS, FUZZY_GROUPS, PROCESSING_INPUT_KEYS, EXACT_PROCESSING_KEYS.
  Request-local State and every public compiler method remain unchanged.
- Eight unused imports. No BigInteger quantity, scheduling, config, machine
  recipe selection, receipt, cancellation or recovery implementation was changed.

The symbolic surplus/byproduct tests now call CompiledRootProgram directly in
CompiledRootProgramSurplusTest. Assertions were retained and the byproduct case
also checks consumed inventory and execution counts. No historical test-only VM
capture/catalog fixture was deleted to improve the result count.

- Upstream bundle size: 1,337,815 -> 1,333,054 bytes. This is artifact cleanup,
  not a measured crafting-speed or server-load improvement.
