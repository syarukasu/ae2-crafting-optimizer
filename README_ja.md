# AE2 Crafting Optimizer 2.0.0

Minecraft 1.20.1 / Forge / Java 17。サーバーとクライアントに同じ版を導入してください。
AE2は15.4.10以上を上限なしで許可します。将来の全バージョンの動作保証ではありません。

- BigIntegerを維持した巨大注文と数式入力。
- 必要量・共有材料・余剰・有限耐久工具の返却を注文全体でまとめて計算。
- 候補と在庫の重複問い合わせを削減。特定アイテムへの特例なし。
- 他MODが見出しを上書きする場合も、計画容量の正しい値を表示。
- 巨大数量のツールチップを科学表記と桁数で表示。
- 実行・電力・在庫・取消・復旧はAE2とCPU側の所有権を維持。

実際のForge GUIでは、制御回路の材料不足計画が`2^63-1`個で5.634秒、
`10^1024-1`個で7.319秒で完了しました。製造完了・巨大注文の全在庫充足・
全環境での性能の保証ではありません。今回の表示修正後の実GUI確認は未実施です。
