# AE2 Crafting Optimizer 2.0.0

Minecraft 1.21.1 / NeoForge / Java 21向けです。
共有のBigInteger計算コアを更新し、巨大計画の共通処理と共有材料の配分を改善しています。
計画容量の見出しと巨大数量ツールチップも修正しました。

今回の表示修正は、Forge側の数式入力・通信機能全体を移植するものではありません。
共有コアを使っていても両版の全機能が同じという意味ではありません。
NeoForgeの新規起動、巨大注文の実製造完了、工具の実環境同等性は未確認です。

固定したVMホストと更新済み共有コアを別々に用意します。
